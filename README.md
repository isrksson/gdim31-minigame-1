# Minigame 1
## Devlog

> *Last Updated: 10/02/2026*

Components are a small unit of data like atoms. Atoms can be built together into a molecule, same how a collection of components form a GameObject. A complex structure of molecules and GameObjects working together work together to form a macromolecule and a scene respectively. Both of these architectural patterns all start from a fundamental unit and scale upwards to form complex and usable systems.
